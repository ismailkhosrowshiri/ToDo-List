# To-Do List

A to-do list project created as part of my frontend development practice.

## Project Contents

The application files are stored in the `ToDo App/` directory.

## Getting Started

1. Clone this repository.
2. Open the `ToDo App/` directory.
3. Open its HTML entry point in a browser.
